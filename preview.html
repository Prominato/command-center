What it looks like on the phone

Rendered from a real snapshot of your backend, taken when this page was built — the same payload the widget receives. Switch colourways to see how the home-screen widgets follow the dashboard. Lock-screen widgets are drawn the way iOS actually renders them: monochrome white on a frosted panel, no colour, because that is a system rule rather than a choice.
Times shown are from the snapshot, so the “now” block is whatever was current when it was taken. On your phone this tracks the real clock and re-renders when the current block ends.
Install steps and the code are on the widget page.
